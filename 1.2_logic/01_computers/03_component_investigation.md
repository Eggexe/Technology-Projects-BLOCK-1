CPU - Primary point for all core computer operations.
RAM - Memory for programs and other processes are stored here, used by the instruction cycle to fetch, decode and execute instructions placed in RAM
Storage - Long term storage that is non-volatile. Files, startup programs and other data is stored here. Not lost when powered off, unlike RAM.
Motherboard - Place where all components are plugged into. Also provides copper trace lines for electricity to travel through so other components can communicate with each other.
Power supply - Converts A/C electricity to D/C electricity which powers electronics. Also lowers voltage to a manageable level.
Cooling - attempts to cool down PC components either by liquid or by air as computation generates heat as a bi-product
